# 腾讯收集表预填与定时提交

适用于普通腾讯文档收集表的油猴脚本。支持预填窗口、默认跟随问卷开放时间，以及到点免刷新提交一次。

## 功能

- 按当前有效题目编号识别题目，过滤更换题型或删除题目留下的旧定义。
- 按表单分别保存预填资料。
- 330×400 像素浮动面板，支持拖动、位置记忆及收起。
- 顶部“常规 / 日志”页签，记录计划时间、触发偏差、请求发起偏差和响应耗时。
- 默认跟随问卷开放时间，支持手动调整，时间按北京时间解释。
- 到点提交一次；网络结果未知时保留记录，避免自动重复提交。

## 安装与使用

[点击安装脚本](https://raw.githubusercontent.com/DreamYuande/tencent-form-prefill/main/qqform-prefill.user.js) · [查看源代码](qqform-prefill.user.js)

1. 在浏览器安装 Tampermonkey 等兼容的用户脚本管理器。
2. 新建脚本，将 `qqform-prefill.user.js` 的完整内容粘贴进去并保存。
3. 登录腾讯文档，打开收集表填写页；已经打开的页面需刷新一次。
4. 在“常规”页预填资料，核对开放时间后启动。
5. 保持页面打开、电脑不休眠。提交后以服务器返回结果和腾讯收集记录为准。

## 支持范围

普通文本、单选、多选、下拉、日期、时间等基础答案结构。附件、图片、签名、定位、矩阵、考试、接龙、打卡、名单身份及条件跳题等特殊流程暂不支持。

本脚本使用腾讯网页内部接口，页面更新可能需要适配。带格式限制的题目需按原表要求填写。验证码需自行处理。

## 时间与日志

脚本使用电脑本机时钟，请在启动前校准系统时间。浏览器后台节流、网络和服务器处理都可能导致延后，不能保证名额或精确到达时间。

日志记录的是脚本触发、发起请求和收到响应的时间；响应耗时不等同于服务器入库耗时。服务器响应头通常只有秒精度。脚本不提前绕过收集时间限制，也不会自动修改系统时间。

## 数据保存

预填答案和最近的状态日志保存在本浏览器的用户脚本存储中。日志不记录报名答案、Cookie 或登录校验值。请求只发往当前腾讯文档同源。

刷新或离开页面会取消尚未发出的定时。已发出的请求不能撤销。请求结果未知时，请先核对腾讯网页记录，再决定是否清除本地提交记录。

## 本地验证

无需第三方依赖，使用 Node.js 运行：

```text
node --check qqform-prefill.user.js
node tests/core.cjs
node tests/active-questions.cjs
```

覆盖有效题目过滤、同名题保留、选项校验、北京时间解析、禁止提前提交、单次发送及未知结果处理。界面、日志和定时流程也在离线表单中做过模拟检查；这些检查不代替不同真实表单环境中的验证。
